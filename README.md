# Breakout — Candy Smash

A bright candy-coated brick breaker with three levels, three lives and a high-score chase.

## Features

- Eight-column brick wall across six colourful rows
- Paddle-angle controls for aiming the ball
- Three lives and three levels, with a faster ball each level
- Score for every brick and a bonus for clearing a level
- Mouse, touch and keyboard paddle movement
- Pause with P or Space at any time
- Win and lose overlays with a play-again button
- High score saved locally between sessions

- A How to play popup with the controls and scoring rules.

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.
